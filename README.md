# 📰 News Agency

**News Agency** is a Django project that allows you to create, edit and view news.
The project was created as part of a learning portfolio to demonstrate practical Django development skills.

**This website includes the following features**:

- Creating, editing, and deleting news articles.
- Display a list of articles, editors, and topics.
- View detailed information about editors and articles.
- Use Bootstrap 5 for a modern responsive design.
- Adapting the free Soft UI Design HTML template to Django.

---

## ⚙️ Technologies

- Python 3.12
- Django 5.2.4
- Bootstrap 5
- SQLite
- [Soft UI Design by Creative Tim](https://www.creative-tim.com/product/soft-ui-design-system)

## 🚀 How to use it

1. **Clone a repository:**
    
    ```bash
    git clone https://github.com/Iryna802498/news-agency.git
    cd news-agency
    ```

2. **Create and activate a virtual environment:**
    
    ```bash
    python -m venv venv
    source venv/bin/activate    # Linux/macOS
    venv\Scripts\activate       # Windows
    ```

3. **Install requirements:**
    
    ```bash
    pip install -r requirements.txt
    ```

4. **Create an .env file based on the example:**
    
    ```bash
    cp .env.sample .env     # Linux/macOS
    copy .env.sample .env   # Windows
    ```

5. **Use migrations:**
    
    ```bash
    python manage.py migrate
    ```

6. **Launch the local server:**
    
    ```bash
    python manage.py runserver
    ```

7. **Use the following credentials:**
    
    Login: admin.user
    Password: admin1234
